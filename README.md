# Teaboom — карточка товара «Ананасовый улун»

Тестовое задание: верстка верхней части карточки товара интернет-магазина

## Запуск

Проект не требует сборки и зависимостей.

1. Скачайте/склонируйте папку целиком (сохранив структуру `index.html`, `css/`, `js/`).
2. Откройте `index.html` в браузере — двойным кликом или через
   `Открыть с помощью → браузер`.

Для корректной работы шрифтов Google Fonts нужен доступ в интернет; если его
нет, страница всё равно отобразится на системных шрифтах-заменителях.

## Структура проекта

```
teaboom/
├── index.html        — разметка карточки товара
├── images/           — изображения
├── css/
│   └── styles.css     — стили: токены, layout, адаптив
├── js/
│   └── main.js         — переключение фасовок, счётчик, кнопка «В корзину»
└── README.md
```

## Что реализовано

- Изображение товара,
  название, категория, артикул, выбор фасовки, цена/старая цена, счётчик
  количества и кнопка «В корзину».
- Переключение фасовки (100 г / 500 г / 1000 г / 5000 г) обновляет цену,
  старую цену, артикул и подсвечивает выбранную кнопку. Поддерживается
  переключение стрелками клавиатуры (роль `radiogroup`).
- Кнопка «В корзину» имеет обычное, hover- и «добавлено»-состояния
  (реальная корзина не подключалась, как и требовалось в задании).
- Блок краткого описания товара под карточкой.
- Адаптивная верстка на Flexbox/Grid, проверена на 1440 / 768 / 375 px:
  на мобильной ширине панель с ценой и кнопкой становится "липкой" внизу
  экрана, фасовки уменьшаются, сетка карточки схлопывается в одну колонку.

## Технологии

Чистый HTML5 / CSS3 (без препроцессоров и Bootstrap) / vanilla JavaScript,
без фреймворков и готовых шаблонов.
